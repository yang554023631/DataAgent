# 修复图表类型选择歧义问题 - 设计文档

## 问题描述

之前prompt中对图表类型的适用场景描述存在歧义：

```markdown
- bar: 柱状图（适合对比、分布）
- pie: 饼图（适合占比分布）
```

导致当用户查询"按性别分布"这类受众分布查询时，LLM因为看到"分布"一词，错误地选择了 `bar` 而不是预期的 `pie`。

## 目标

修改prompt的图表类型说明，**消除歧义**，让LLM能够正确选择：
- `audience_distribution` → `pie`（饼图展示占比）
- `entity_table` → `table`（表格展示明细）
- `time_trend` → `line`（折线图展示趋势）
- `period_comparison` → `bar`（柱状图展示对比）

## 最终设计

### 修改后的完整图表说明

```markdown
## 可用的图表类型（chart type）
- line: 折线图（适合时间趋势）
- bar: 柱状图（适合**同一指标在不同类别之间的数值对比**，例如：广告主6 三四月份的消耗对比；广告主6 三四月份的消耗和点击对比（每个指标分别对比两个月份，多系列柱状图））
- pie: 饼图（适合占比分布，特别是受众分布场景，比如按性别、年龄、操作系统、系统版本、兴趣、国家、城市等受众维度的分布）
- table: 表格（适合明细数据，展示多个实体多个指标的详细数值）

### 分析类型与推荐图表
根据分析类型，请优先选择以下图表：
- time_trend（时间趋势）→ line（必须使用折线图）
- period_comparison（时期对比）→ bar（柱状图）
- audience_distribution（受众分布）→ pie（饼图，展示占比）
- entity_table（实体列表）→ table（表格，展示明细列表）
- summary（数据摘要）→ table（表格）
```

## 设计要点

1. **移除歧义**：从 `bar` 的描述中删除了"分布"二字，只保留"适合对比"
2. **明确场景**：在 `pie` 的描述中列出了所有支持的受众维度（性别、年龄、操作系统、系统版本、兴趣、国家、城市），明确告诉LLM这些分布场景用pie
3. **简化规则**：`entity_table` 一律推荐 `table`，不需要复杂判断，符合现有测试用例实际情况
4. **增加例子**：在 `bar` 的描述中增加了具体对比例子，帮助LLM更好理解适用场景

## 修改范围

只修改 `backend/src/analysis/prompts.py` 中的 `COT_SYSTEM_PROMPT` 里的图表类型说明部分，不涉及其他代码改动。
