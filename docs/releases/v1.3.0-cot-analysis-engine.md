# v1.3.0 - CoT 链式思维分析引擎

## 发布日期
2026-08-10

## 核心功能

### 1. 核心架构升级

**全量替换报表链路为 CoT 驱动的 analysis_node**

- 原有 `report_intent → planner/nl_dsl → reporter` 链路已被单个 `analysis_node` 节点替换
- 顶层 `intent_classifier` 保留，负责三类意图分发（report / knowledge / out_of_domain）
- 所有报表查询统一走 CoT 流程，避免双路径维护成本

**两阶段分析，逐步推理**

- **筛选阶段**：判断筛选类型、提取筛选条件、确定目标实体层级
- **分析阶段**：判断分析形态、确定图表类型、提取指标与维度
- 每阶段内部通过 CoT（链式思维）逐步推理，提升复杂查询准确率

**4 种筛选类型**

| 类型 | 说明 | 典型例子 |
|---|---|---|
| **none** | 不筛选，全量实体 | "所有广告计划" |
| **where** | 属性/维度过滤（行级） | "状态为投放中的计划" |
| **having** | 指标聚合后过滤 | "消耗>10的计划" |
| **cross_level** | 跨层级筛选（上钻/下钻） | "创意名包含XX的计划" |

**5 种分析形态**

| 形态 | 图表类型 | 核心特征 |
|---|---|---|
| **entity_table** | bar / table | 每行一个实体，多列指标 |
| **time_trend** | line | 按时间粒度的变化曲线 |
| **period_comparison** | bar / line | 两时间段对比 |
| **audience_distribution** | pie / ring | 按受众维度的占比 |
| **summary** | kpi_card | 几个汇总数字 |

### 2. SSE 流式进度推送

- **步骤级进度显示**：6 个步骤逐一推送，用户实时感知分析进展
  1. `intent_analyze` — 理解查询意图
  2. `cot_planner` — 生成分析计划
  3. `filter_execute` — 执行筛选查询
  4. `analysis_execute` — 执行分析查询
  5. `quality_check` — 质量校验
  6. `report_format` — 组装最终报告
- **实时反馈**：将 ~15s 的等待过程转化为有明确进度感知的体验
- **自动断线处理**：3s 内自动重连，携带上次事件 ID，避免进度丢失

### 3. 质量校验 + HITL 机制

**查询后质量校验**

| 校验项 | 默认阈值 | 动作 |
|---|---|---|
| max_series_count（多系列趋势） | 20 条线 | HITL 提示缩小范围 |
| max_rows（实体表） | 100 条 | 截取 Top N + 提示 |
| max_categories（受众分布） | 8 类 | Top N-1 + "其他"合并 |
| min_data_points（趋势图） | 2 个 | 降级为单值显示 |
| all_zero（全零数据） | — | 警告提示 |
| empty_result（空结果） | — | 友好提示 + 建议 |

**信息缺失型 HITL**

- 筛选阶段缺失：广告主、时间范围、目标层级、筛选条件、阈值
- 分析阶段缺失：指标、对比期、受众维度
- 一次只澄清一个问题，逐步完善
- **字段共享池**：已确认的字段在筛选/分析两阶段间共享，避免重复询问

**质量型 HITL**

- 多系列趋势图超 20 条线时，提示用户缩小范围或查看 Top 20
- 提供快捷选项，降低用户输入成本

### 4. 前端升级

**全新 V2 报告格式**

- `success` — 正常报告（图表 + 数据表 + 质量提示）
- `error` — 错误报告（错误类型 + 原因 + 行动建议 + 推荐查询）
- `empty` — 空结果提示（友好文案 + 调整建议）
- `hitl` — 澄清交互（问题 + 选项 + 快捷回复）

**增强图表**

- 饼图 / 环形图（受众分布）
- KPI 卡片（单值汇总，支持多指标并排）
- 多系列折线图（时间趋势，支持图例切换）
- 数据表（配套展示，支持排序）

**步骤进度指示器**

- 顶部进度条 + 步骤标签
- 当前步骤高亮，已完成步骤打勾
- 与 SSE 事件实时同步

**质量问题展示组件**

- 质量警告以醒目方式展示
- 截断/合并说明清晰可见
- 支持 HITL 快捷操作

**向后兼容**

- 保留 V1 报告格式渲染能力
- 旧版接口返回的数据仍可正常展示

### 5. 技术架构

**Graph 路由**

```
intent_classifier → analysis_node → END
       (report)
```

**analysis_node 内部模块（顺序执行）**

```
IntentAnalyzer → CotPlanner → FilterExecutor → EmptyResultChecker → AnalysisExecutor → QualityChecker → ReportFormatter
   (字段提取)    (CoT推理+计划)   (筛选执行)      (空结果预判)        (分析+图表组装)     (质量校验)       (报告包装)
```

**关键技术点**

- **向量检索 Few-Shot**：基于 PostgreSQL + pgvector，动态检索最相关的示例注入 prompt
- **派生指标计算**：CTR / CVR / ROI 等衍生指标通过 bucket_script 管道聚合在 ES 侧计算
- **DSL 安全校验**：禁止脚本注入、限制 size/terms 数量、防止深度嵌套聚合
- **LangGraph 状态管理**：新增 7 个状态字段，旧字段平滑废弃

### 8. 后续优化方向

1. **P0 模板快速通道**：高频简单查询（如"广告主X最近7天消耗趋势"）用关键词规则直接匹配模板，跳过 CoT 推理，将延迟从 ~15s 降至 ~1-2s
2. **更多分析维度**：地域、设备、兴趣标签等受众维度的深度分析
3. **洞察结论自动生成**：结合 RAG 知识库，自动从数据中提炼洞察结论和优化建议
4. **报表导出功能**：支持 Excel / PDF 格式的报表导出
5. **SSE 断线重连优化**：完善断线重连后的进度恢复机制
6. **更多分析形态**：漏斗分析、留存分析、归因分析等高级分析场景
7. **智能推荐查询**：基于当前查询上下文，智能推荐下一个可能的分析方向
